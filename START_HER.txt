🚀 SLIK STARTER DU

  1. Åpne kommandolinja i "Ny mappe"
  
  2. Instaler Python-pakker:
     $ pip install -r requirements.txt
  
  3. Start serveren:
     $ python app.py
  
  4. Åpne nettleser:
     http://localhost:5000
  
  5. Test funksjonaliteten:
     - Registrer ny bruker
     - Logg inn
     - Gå til Dashboard
     - Lagre data!

💡 TIPS FOR SKALERING

  Legge til ny side:
  ─────────────────
  1. Rediger config.py → legg til menysystem
  2. Opprett HTML-template
  3. Legg til @routes i pages.py
  ✓ Ferdig!

  Legge til lagringsfunksjon:
  ───────────────────────────
  JavaScript: await StorageAPI.setData('nøkkel', 'verdi')
  
  Eller opprett egen API i pages.py hvis du trenger komplekst.

  Tilpasse design:
  ────────────────
  Rediger static/css/style.css
  - Farger: :root { --primary-color: ... }
  - Layout: Grid og flexbox

❓ FEILSØKING

  Problem                         Løsning
  ───────────────────────────────────────────────────────────────────────
  "ModuleNotFoundError: flask"    pip install -r requirements.txt
  "TemplateNotFound"              Sjekk at HTML er i templates/-mappen
  Port 5000 er i bruk             Rediger port i app.py (linje: app.run)
  Database-feil                   Slett db/database.db og start på nytt
  CSS virker ikke                 Sjekk at static/css/style.css finnes
