## 🚀 NESTE STEG - Start her!

### 1. Opprett mappestruktur
Opprett disse mappene i samme mappe som app.py:
```
templates/
templates/components/
static/
static/css/
static/js/
db/
```

Eller la app.py gjøre det automatisk! 👇

### 2. Installer avhengigheter
```bash
pip install -r requirements.txt
```

### 3. Start serveren
```bash
python app.py
```

Serveren oppretter automatisk:
- ✅ Mappestrukturen
- ✅ Databasefilen
- ✅ Organiserer templates og static-filer

### 4. Besøk http://localhost:5000
Se nettsiden live!

## 📋 Hvordan legge til ting

### Ny sidemeny-item
1. Legg til i MENU_ITEMS i `config.py`
2. Opprett template
3. Legg til @routes i `pages.py`
✅ FERDIG - siden er synlig i menyen!

### Ny lagringsfunksjon
Bruk StorageAPI fra main.js:
```javascript
await StorageAPI.setData('nøkkel', 'verdi');
await StorageAPI.getData('nøkkel');
await StorageAPI.deleteData('nøkkel');
```

### Kompleks datalagrting
1. Opprett ny tabell i `database.py`
2. Legg til API-ruter i `pages.py`
3. Kall fra frontend

Se DEVELOPMENT.md for detaljert guide!

## 🔒 Sikkerhet

- ✅ Passord hashes med bcrypt
- ✅ SQL-injeksjon-beskyttet (ORM)
- ✅ Sesjonbasert autentisering
- ✅ CSRF-ready (kan aktiveres)

I produksjon:
- Sett `SESSION_COOKIE_SECURE = True` i config.py
- Bruk HTTPS
- Endre `SECRET_KEY` til sterk verdi
